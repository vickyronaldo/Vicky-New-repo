# Exercise 2 Intune Quick Intro

## Intune quick summary (easy understanding)

1. Intune is Microsoft’s cloud tool to manage and secure company devices.
2. It manages laptops and phones: Windows, Mac, iPhone/iPad, and Android.
3. IT teams can push settings, security rules, apps, and updates remotely.
4. It checks device health (compliance), like password, encryption, and patch status.
5. With Conditional Access, only safe and compliant devices can open company apps like Outlook, Teams, and SharePoint.
6. It supports both:
   - Company-owned devices (full control)
   - Personal devices (protects work data without full personal control)
7. With Autopilot, new devices can be set up automatically when users sign in.
8. Main benefit: better security and easier IT management, especially for remote or hybrid work.

## One-line memory aid

Intune = control devices, protect company data, and allow access only from trusted devices.
