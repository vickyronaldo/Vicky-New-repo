# Copilot Prompting Starter Guide (FinBridge)

Date: 2026-08-12  
Audience: Non-technical office staff  
Goal: Help you get better, faster results from Microsoft 365 Copilot in everyday work.

## Quick Start: The 4-Part Prompt Formula

Use this simple formula every time:

**Task + Context + Output + Rules**

What this means:
- **Task**: What you want Copilot to do
- **Context**: Which meeting/email/document/data it should use
- **Output**: What format you want back
- **Rules**: Tone, length, deadline, audience, must-include items

Easy version to remember:
- **"Do this, using this, in this format, with these rules."**

### Copy-and-reuse prompt template

"Please [task] using [context/source]. Return it as [output format]. Keep it [tone/length] and include [must-have points]."

## Outlook: Real Prompt Examples

Use these as-is, then edit names/dates.

### Example 1: Catch up after leave

"Summarise my unread emails from the last 5 business days. Group by: urgent decisions, deadlines this week, and FYI updates. Give me a bullet list and suggest 3 replies I should send first."

### Example 2: Draft a clear stakeholder update

"Draft an email to the Finance leadership team updating them on the month-end close status. Use a professional but plain tone. Include: what is complete, what is at risk, and what decisions are needed by Friday 3pm. Keep it under 180 words."

### Example 3: Turn a long thread into an action email

"Read this email thread and draft a response that confirms next steps. Include owners and dates for each action. End with one clear question asking for approval to proceed."

### Tips for better Outlook prompts

- Say **who** the email is for (manager, client, project team).
- Ask for a **word limit** so drafts are concise.
- Ask Copilot to include **actions, owners, and due dates**.

## Word: Real Prompt Examples

### Example 1: First draft from meeting notes

"Using my notes in this document, create a one-page project update for the COO. Structure it with: Summary, Progress this week, Risks, Decisions needed. Keep it concise and business-focused."

### Example 2: Improve readability of an existing draft

"Rewrite this document in plain English for non-technical colleagues. Keep all key facts, remove jargon, and shorten long sentences. Then provide a final version plus a short list of what you changed."

### Example 3: Create an executive summary

"Create a 7-bullet executive summary of this report for the board prep pack. Focus on financial impact, timeline risk, and decisions required this month."

### Tips for better Word prompts

- Name your audience: **board, leadership, operations, client**.
- Ask for a structure: **headings + bullet points**.
- Ask Copilot to do a quick quality check: "highlight anything unclear or missing evidence."

## Excel: Real Prompt Examples

### Example 1: Explain trends simply

"Analyse this table and identify the top 5 departments where spend is most over or under budget this quarter. Show: department, amount, likely reason, and a one-line recommendation."

### Example 2: Build a management summary from data

"From this worksheet, create a short monthly performance summary for Finance managers. Include revenue trend, cost trend, and any unusually large changes (over 10%) compared with last month."

### Example 3: Prepare data for follow-up actions

"Find rows where invoice status is 'Overdue' and amount is above 50000. Group by account owner and draft a follow-up action list with priorities High/Medium/Low."

### Tips for better Excel prompts

- Name the number you care about: **difference from budget, trend, unusual change, forecast**.
- Set thresholds: **"above 10%"**, **"over 50000"**.
- Ask for an action-oriented output, not just analysis.

## Make Prompts Better in 10 Seconds

If Copilot gives a weak answer, add one of these:

- "Use bullet points and keep it under 8 lines."
- "Focus only on actions due this week."
- "Rewrite this for senior leadership in plain English."
- "Include risks, owner, and due date for each action."
- "What information is missing to improve this answer?"

## Data Safety Habit (Important)

From Day 1 of this programme: **treat data protection as a daily habit**.

Copilot is there to help with your normal work in Microsoft 365. Most day-to-day drafting, summarising, and organising tasks are absolutely fine to use.

- Use Microsoft 365 Copilot with approved company data and permissions.
- **Do not paste confidential client data, payroll data, board material, or M&A content into external AI tools.**
- If you are unsure whether data is safe to use, pause and quickly check with your manager or the DWP/Security team.

Simple rule:
- **Keep sensitive work inside approved company tools. Do not paste confidential information into public/external AI sites.**

## Your First 5-Day Copilot Habit

Day 1-2:
- Use the 4-part formula for every prompt.
- Start with short tasks (summaries, draft replies, action lists).

Day 3-4:
- Add constraints (word limit, audience, due date).
- Ask for "actions + owners + dates" in outputs.

Day 5:
- Reuse your 3 best prompts and save them in your team notes.
- Share one good prompt with a colleague.

## One-Page Prompt Cheat Sheet

Use this sentence starter:

"Please [task] using [context]. Return as [format]. Keep it [tone/length]. Include [must-have items]."

Example:

"Please draft a status email using this meeting thread. Return as a concise email draft. Keep it professional and under 150 words. Include key risks, owners, and deadlines."

When in doubt:
- Be specific
- Name your audience
- Ask for format
- Add constraints
- Protect sensitive data
